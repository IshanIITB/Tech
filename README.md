Welcome to IIT Bombay Tech Community’s official tech community page, where caffeine unites with code and deadlines become nothing more than suggestions!

## Overview

This is the place for all of the things that happen in our tech community, from the creations to the destruction of things in production. We bring together students with an obsession of writing code, debugging code and finally attributing everything that goes wrong to that very code!

Our aim at IITB Tech Community is simple — let's create incredible stuff together.

## What's in Here?

- Schedule of events — workshops, hackathons, tech talks
- Projects by members of this tech community
- Useful guides about web development, ML, competitive programming etc.
- A blog with sporadic posts not limited to saying ‘Hello World’ only


## Tech Stack used here

- **Frontend:** React / Next.js
- **Backend:** Node.js / Express
- **Database:** MongoDB
- **Styling:** TailwindCSS
- **Deployment:** Vercel
- (Indeed, we are aware that there are countless other methods for achieving this, but this method is the one to which we have successfully turned.) ## Getting Started 

```bash 
git clone https://github.com/iitb-tech-community/website.git 
cd website 
npm install 
npm run dev 
```
 
Next, open [http://localhost:3000](http://localhost:3000) and keep your fingers crossed. 
## Contributing 

We warmly welcome anyone to take part in this process, irrespective of whether you are a first-year student and have just come to know what `git push` even means or a person in their final year who has forgot more things about React than the others have ever learned. 
1. Fork the repository
2. Create a new branch (`git checkout -b feature/your-feature`)
3. Make the necessary changes
4. Commit (`git commit -m "Add feature"`)
5. Push and create Pull Request
6. Wait for a while for someone to review your work
 
Please do not push directly to `main`. It has never been a pleasant experience.
